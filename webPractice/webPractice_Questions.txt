•	Your CSS inside the <style> tag — design and layout.
•	./02_functions/basicfunction2.js — JavaScript functions.
For each question:
1.	Write the HTML element or button.
2.	Add the JavaScript function.
3.	Use arrays, loops, conditions or DOM methods when the question requires them.
4.	Test it in your browser and inspect the Console if something goes wrong.
5.	Try to solve it yourself before checking a solution.
My recommendation: Start with Questions 21–40, because they directly extend your current random background color exercise. Then progress through the sections in order. You don't need to complete all 200 in one day, sir; solve them one by one and practise until you can write the code without looking at examples.
